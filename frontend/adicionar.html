Instruções para Upload

📋 Formato do Arquivo:

  • • Arquivo Excel (.xlsx ou .xls)
  • • Primeira linha deve conter os cabeçalhos
  • • Colunas esperadas: part_number, description, ncm, etc.
  • • Máximo de 10.000 linhas por upload

📊 Colunas da Tabela (Atualizada):

  • • part_number (Part Number) - Número inteiro
  • • chinese_description (Descrição Chinesa) - Texto
  • • description (Descrição) - Texto
  • • ncm (NCM) - Número inteiro
  • • origin (Origem) - Número inteiro
  • • date_of_creation (Data de Criação) - Data
  • • review_date (Data de Revisão) - Data
  • • requester (Solicitante) - Texto
  • • machine (Máquina) - Texto

⚠️ Instruções Importantes:

  • • Use o arquivo modelo fornecido como base
  • • Mantenha os nomes das colunas exatamente como mostrado
  • • Campos obrigatórios: part_number, description, ncm, date_of_creation
  • • Formato de data: M/D/YYYY (ex: 2/5/2025) ou YYYY-MM-DD (ex: 2024-01-15)
  • • part_number e ncm devem ser números inteiros
  • • origin deve ser um número inteiro (1, 2, 3, etc.)
  • • Verifique se o arquivo não está aberto
  • • Certifique-se de que não há linhas vazias
  • • Dados duplicados serão ignorados
  • • O processo pode levar alguns minutos
